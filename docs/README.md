# docs/

**Purpose:** Architecture, operations, and governance documentation for the VedMoulya monorepo.

## Contents

| Directory / File             | Description                                                                 |
| ---------------------------- | --------------------------------------------------------------------------- |
| `adr/`                       | Architecture Decision Records — key technical decisions and their rationale |
| `api/`                       | API specifications and contracts                                            |
| `guides/`                    | Developer guides and onboarding documentation                               |
| `ops/`                       | Operations runbooks and deployment procedures                               |
| `runbooks/`                  | Incident response, recovery, and maintenance runbooks                       |
| `BLD-*.md`                   | Module implementation and certification reports                             |
| `RC-*.md`                    | Release candidate verification reports                                      |
| `PLATFORM_CLOSURE_REPORT.md` | Platform completion summary                                                 |

## Usage

- **Architecture decisions**: See `adr/` for all ADRs numbered by date
- **API contracts**: See `api/` for OpenAPI specs and tRPC router manifests
- **Runbooks**: See `runbooks/` for operational procedures
- **Release docs**: `RC-*.md` files contain full verification reports for each release candidate

## Ownership

**Owner:** Engineering Team

## Maintenance

- All documentation is version-controlled in this monorepo
- ADRs are immutable once accepted — superseded ADRs are marked with a `Superseded by` header
- Release reports are generated by the CI pipeline and reviewed before each RC
