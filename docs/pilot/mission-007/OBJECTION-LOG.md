## 1. Entry format (copy one block per objection)

```text
DATE:        [YYYY-MM-DD]
PROSPECT:    [initials or first name — not a full name in a shared file]
STAGE:       [first outreach | discovery call | follow-up | proposal review | post-acceptance]
OBJECTION:   "[verbatim — their exact words, including the uncomfortable ones]"
CONTEXT:     [what you had just said, one line]
CATEGORY:    [one of §2]
MY ANSWER:   "[exactly what you said back]"
DID IT LAND?  [accepted | partially | no | unknown] + how you know
CHANGE?      [none | offer | price | scope | disclosure | qualification] + what changed
FOLLOW-UP:   [dated action, or "closed — no"]
```

## 2. Categories (use exactly one per entry)

| Code            | Meaning                                         | Typical trigger                                |
| --------------- | ----------------------------------------------- | ---------------------------------------------- |
| `price`         | Too expensive, or wrong structure               | "1,500 for one article?"                       |
| `value`         | Does not believe the problem is worth money     | "I've never really lost money this way"        |
| `trust`         | Wants proof, references, or a familiar name     | "Who else has done this?"                      |
| `ai-scepticism` | Doubts the AI quality or authenticity           | "Is this just ChatGPT?"                        |
| `technical`     | Questions about the ledger's behaviour          | "What if my bookkeeper re-enters it?"          |
| `scope`         | Wants more than the pilot includes              | "Could it also do invoices for my whole team?" |
| `commitment`    | Time, calendar or decision authority            | "I can't do three sessions in three weeks"     |
| `alternative`   | Prefers an existing tool or a person            | "My accountant already does this"              |
| `timing`        | Wants it later                                  | "Ask me in Q1"                                 |
| `other`         | Anything genuinely different — write what it is | —                                              |
