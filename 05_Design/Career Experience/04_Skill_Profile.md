# Skill Profile

> **Document:** DES-006-D04 — Career Operating System Experience  
> **Status:** 🔒 **LOCKED** — Part of DES-006 Career Constitution v1.0

---

## Purpose

The Skill Profile is the user's complete skill inventory — what they know, how proficient they are, and how their skills connect to career goals. Skills are organized by category, proficiency, and relevance.

## Skill Categories

| Category           | Examples                                            |
| ------------------ | --------------------------------------------------- |
| **Technical**      | Programming, tools, platforms, frameworks           |
| **Soft Skills**    | Leadership, communication, teamwork, empathy        |
| **Domain**         | Industry-specific knowledge, regulations, practices |
| **Management**     | People management, project management, strategy     |
| **Languages**      | Natural languages, proficiency level                |

| Level | Label        | Description                                 |
