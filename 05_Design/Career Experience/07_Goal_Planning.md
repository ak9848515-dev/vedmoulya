# Goal Planning

> **Document:** DES-006-D07 — Career Operating System Experience  
> **Status:** 🔒 **LOCKED** — Part of DES-006 Career Constitution v1.0

---

## Purpose

Goal Planning helps users break down career aspirations into actionable goals with clear milestones, timelines, and progress tracking.

---

## Goal Types

| Type                 | Example                                       | Tracking                               |
| -------------------- | --------------------------------------------- | -------------------------------------- |
| **Skill goal**       | "Complete TensorFlow certification by Dec"    | Course progress, quiz scores           |
| **Role goal**        | "Become Senior Engineer within 12 months"     | Skill acquisition, promotion readiness |
| **Application goal** | "Submit 10 quality applications per month"    | Application count, response rate       |
| **Network goal**     | "Connect with 5 industry leaders per quarter" | Connection count, conversation depth   |
| **Project goal**     | "Ship portfolio project demonstrating X"      | Project milestones, feedback           |
