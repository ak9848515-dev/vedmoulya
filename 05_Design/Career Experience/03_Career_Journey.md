# Career Journey

> **Document:** DES-006-D03 — Career Operating System Experience  
> **Status:** 🔒 **LOCKED** — Part of DES-006 Career Constitution v1.0

---

## Purpose

The Career Journey shows the user's complete professional path — past roles, current position, future aspirations. It feels like walking through a career timeline, not browsing a resume.

---

## Career Timeline

```
PAST                  PRESENT                  FUTURE
────                  ───────                  ──────
2018 ─ 2020 ─ 2022 ─ 2024 ─ 2026 ─ 2028 ─ 2030 ─ 2032
  │       │       │      │       │       │       │
  Jr Dev  Mid     Sr     Lead    Sr      Dir     Exec
          Dev     Dev    (now)   Leader  (goal)
```

| Element          | Specification                                                |
| ---------------- | ------------------------------------------------------------ |
| **Past roles**   | Company, title, duration, key achievements                   |
| **Current role** | Highlighted, expandable for details                          |
| **Future goals** | Dashed outline, user-defined aspirations                     |
| **Transitions**  | Animated connection lines between roles                      |
| **Gaps**         | Acknowledged neutrally — sabbaticals, education, exploration |

## Career Stage Cards

| Stage                | Card Content                                         | Emotion                 |
| -------------------- | ---------------------------------------------------- | ----------------------- |
| Student              | Education, internships, skills building              | Exploration             |
| Fresher              | First job search, resume, interview prep             | Eagerness + nervousness |
| Working Professional | Role growth, promotion track, skill development      | Ambition                |
| Career Switcher      | Transition plan, gap analysis, learning path         | Uncertainty + hope      |
| Manager              | Team size, management skills, leadership development | Responsibility          |
| Leader               | Vision, strategy, mentorship, board readiness        | Legacy                  |
| Freelancer           | Client pipeline, rates, portfolio, project history   | Independence            |
| Entrepreneur         | Venture milestones, fundraising, team building       | Creation                |
| Return-to-work       | Skill refresh, confidence building, flexible options | Re-entry                |
| Retired Mentor       | Advisory, mentorship, part-time consulting           | Wisdom                  |
