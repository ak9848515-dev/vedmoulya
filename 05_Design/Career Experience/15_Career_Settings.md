# Career Settings

> **Document:** DES-006-D15 — Career Operating System Experience  
> **Status:** 🔒 **LOCKED** — Part of DES-006 Career Constitution v1.0

---

## Purpose

Career Settings allows users to control their career data, preferences, privacy, and integrations.

---

## Settings Sections

| Section             | Settings                                                |
| ------------------- | ------------------------------------------------------- |
| **Profile**         | Career stage, industry, role, experience level          |
| **Privacy**         | Resume visibility, job search status, profile sharing   |
| **Preferences**     | Job types, locations, company size, salary range        |
| **Integrations**    | LinkedIn import, resume upload, portfolio connection    |
| **Notifications**   | Application updates, interview reminders, weekly review |
| **Data management** | Export all career data, delete career history           |

---

## Privacy Controls

| Setting                 | Options                                   |
| ----------------------- | ----------------------------------------- |
| Job search visibility   | Hidden / Recruiters only / Public         |
| Resume visibility       | Private / Recruiters / Public             |
| Career insights sharing | Private / Anonymized / Mentor access only |
| Data export             | JSON, CSV, PDF                            |
