# Resume & Portfolio

> **Document:** DES-006-D08 — Career Operating System Experience  
> **Status:** 🔒 **LOCKED** — Part of DES-006 Career Constitution v1.0

---

## Purpose

The Resume & Portfolio experience helps users create, maintain, and export professional artifacts — resumes, portfolios, project showcases, and achievement records.

---

## Resume Builder

| Feature                | Specification                                                         |
| ---------------------- | --------------------------------------------------------------------- |
| **Templates**          | 5 templates (Modern, Classic, Technical, Executive, Creative)         |
| **AI Suggestions**     | Recommends bullet points based on experience, quantifies achievements |
| **Section management** | Summary, Experience, Education, Skills, Certifications, Projects      |
| **Export**             | PDF, DOCX, JSON (ATS-friendly), Web link                              |
| **Version history**    | Track changes, revert to previous versions                            |
| **Tailor for role**    | Auto-prioritize relevant experience for target job                    |

---

## Portfolio

| Feature                  | Specification                                     |
| ------------------------ | ------------------------------------------------- |
| **Project showcase**     | Title, description, technologies, links, outcomes |
| **Achievement timeline** | Chronological achievement display                 |
| **Impact metrics**       | Quantified results, before/after comparisons      |
| **Testimonials**         | Colleague/manager recommendations (user-added)    |
| **Share**                | Public profile URL, privacy controls              |
