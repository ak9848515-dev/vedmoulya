## Preamble

This Constitution establishes the Career Experience for VedMoulya — a complete Career Operating System that helps users discover, prepare, improve, apply, interview, grow, transition, and succeed throughout their entire professional journey. This is NOT a job portal, NOT LinkedIn, NOT a resume builder. It is a lifelong career companion.

**All specifications follow DES-001 v1.0, DES-002A v1.0, DES-003A v1.1, DES-004 v1.0, and DES-005 v1.0 exactly.**

## 3. Career Stages (LOCKED)

The Career Experience adapts to the user's current career stage:

| Stage                    | Focus                                      | Experience                                 |
| ------------------------ | ------------------------------------------ | ------------------------------------------ |
| **Student**              | Discovery, skill building, internships     | Guided exploration, learning paths         |
| **Fresher**              | First job, resume building, interview prep | Application tracking, skill emphasis       |
| **Working Professional** | Growth, promotion, skill development       | Career roadmap, performance tracking       |
| **Career Switcher**      | Transition, gap analysis, new industry     | Skill mapping, learning recommendations    |
| **Manager**              | Leadership, team management, influence     | Management skills, team metrics            |
| **Leader**               | Executive presence, strategy, vision       | Strategic planning, board readiness        |
| **Freelancer**           | Project pipeline, client management, rates | Portfolio, invoicing, client relationships |
| **Entrepreneur**         | Venture building, fundraising, team        | Business milestones, investor readiness    |
| **Return-to-work**       | Re-entry, confidence, skill refresh        | Skill refresher, flexible opportunities    |
| **Retired Mentor**       | Legacy, advisory, part-time                | Mentorship matching, advisory roles        |

## 4. Information Hierarchy (LOCKED)

```
P0 — ALWAYS VISIBLE:
  • Career Readiness Score
  • Current focus (goal, application, interview)
  • Next best action

P1 — SHOWN BY DEFAULT:
  • Skill profile (top skills + gaps)
  • Career roadmap (milestones + timeline)
  • Active applications (count + status)
  • Upcoming interviews
  • AI Career Coach presence

P2 — CONTEXTUAL:
  • Skill gap analysis details
  • Job discovery results
  • Application manager (per-application detail)
  • Interview prep materials
  • Resume/portfolio editor
  • Career analytics

P3 — ON DEMAND:
  • Full career history
  • Salary planning
  • Career settings
```

## 5. AI Career Coach Rules (LOCKED)

| Rule                          | Implementation                                            |
| ----------------------------- | --------------------------------------------------------- |
| **Uses DES-005 Mentor**       | Career Coach is the DES-005 Mentor in Career Coach mode   |
| **Never fabricates feedback** | No fake recruiter feedback, no inside knowledge claims    |
| **Distinguishes sources**     | Facts ≠ user history ≠ market observations ≠ suggestions  |
| **No promises**               | Never guarantees outcomes (jobs, offers, promotions)      |
| **Ethical boundaries**        | No discrimination advice, no dishonesty suggestions       |
| **Honest uncertainty**        | "I don't know" over confident speculation about employers |
