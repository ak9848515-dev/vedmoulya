# Responsive Experience

> **Document:** DES-006-D16 — Career Operating System Experience  
> **Status:** 🔒 **LOCKED** — Part of DES-006 Career Constitution v1.0

---

## Purpose

The Career Experience must feel native on every device — from mobile job discovery on the go to desktop resume editing.

---

## Device Layouts

| Device                | Career Dashboard                       | Application Manager           | Resume Builder        |
| --------------------- | -------------------------------------- | ----------------------------- | --------------------- |
| **Mobile (<480px)**   | Single column, readiness + next action | Simplified kanban (2 columns) | Full-screen editor    |
| **Tablet (768px)**    | 2-column: readiness + progress         | 4-column kanban scrollable    | Side-by-side preview  |
| **Desktop (1280px+)** | Full 4-zone layout                     | Full kanban with detail panel | Live preview + editor |
