# Career Roadmap

> **Document:** DES-006-D06 — Career Operating System Experience  
> **Status:** 🔒 **LOCKED** — Part of DES-006 Career Constitution v1.0

---

## Purpose

The Career Roadmap shows the user's planned career trajectory — next milestone, intermediate steps, and long-term vision. It transforms abstract career aspirations into a concrete, time-bound path.

---

## Milestone Types

| Type                 | Description                     | AI Involvement                          |
| -------------------- | ------------------------------- | --------------------------------------- |
| **Role transition**  | Moving to next role             | Suggests timeline, skills, companies    |
| **Skill milestone**  | Reaching target proficiency     | Recommends learning resources           |
| **Certification**    | Professional certification      | Prepares study plan, tracks progress    |
| **Application goal** | Target number of applications   | Tracks pipeline, suggests opportunities |
| **Interview target** | Interview preparation milestone | Mock interviews, feedback               |
