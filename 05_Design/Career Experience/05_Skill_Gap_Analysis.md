## Purpose

Skill Gap Analysis identifies what skills the user has, what skills they need for their target role, and a prioritized plan to close the gap.

---

## Gap Analysis Flow

```
1. CURRENT STATE → Import skills from profile
2. TARGET STATE → Select target role (from roadmap or job discovery)
3. COMPARISON → AI matches skills to target requirements
4. PRIORITIZATION → Critical → High → Medium → Low
5. LEARNING PLAN → Recommended courses, projects, practice
6. TIMELINE → Estimated months to close each gap
```
