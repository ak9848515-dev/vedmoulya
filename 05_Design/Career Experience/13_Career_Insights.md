# Career Insights

> **Document:** DES-006-D13 — Career Operating System Experience  
> **Status:** 🔒 **LOCKED** — Part of DES-006 Career Constitution v1.0

---

## Purpose

Career Insights provide personalized observations about the user's career — patterns, strengths, risks, and opportunities — derived from their data, not generic advice.

---

## Insight Types

| Type                    | Example                                                    | Source                     |
| ----------------------- | ---------------------------------------------------------- | -------------------------- |
| **Strength insight**    | "You consistently perform well in cross-functional roles." | Work history + feedback    |
| **Growth insight**      | "Your skills have grown 40% in the past year."             | Skill progression          |
| **Risk insight**        | "Leadership skill development has plateaued for 6 months." | Stalled progress detection |
| **Opportunity insight** | "Companies in your network are hiring for matching roles." | Network + market data      |
| **Pattern insight**     | "You tend to stay in roles for 18-24 months."              | Career timeline patterns   |
| **Market insight**      | "Your skills are in the top 15% for target roles."         | Market comparison          |

## Salary Planning

| Aspect                 | Specification                                                                                                           |
| ---------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| **Purpose**            | Help users understand their market value, negotiate offers, and plan financial growth                                   |
| **Market data**        | AI-curated salary ranges by role, seniority, location, industry (with source attribution: "Market data from [sources]") |
| **Personal benchmark** | "Based on your skills and experience, your estimated range is $X-$Y"                                                    |
| **Offer evaluation**   | Compare offer components: base, equity, bonus, benefits                                                                 |
| **Negotiation prep**   | Suggested talking points, market evidence to cite                                                                       |
| **Growth projection**  | "At your current trajectory, projected compensation in 3 years: $X-$Y"                                                  |
| **AI boundary**        | Never guarantees specific offers. Always shows uncertainty. "Estimates based on market data — actual offers vary."      |
| **Privacy**            | Salary data is never shared. Never stored externally.                                                                   |

---

## Networking

| Aspect                     | Specification                                                                            |
| -------------------------- | ---------------------------------------------------------------------------------------- |
| **Purpose**                | Help users build and maintain professional relationships that support career growth      |
| **Network view**           | Simple list of connections with relationship strength indicator (light/medium/strong)    |
| **Connection suggestions** | "People in target roles at target companies you could connect with"                      |
| **Relationship tracking**  | Last interaction date, context, follow-up reminders                                      |
| **Interaction prompts**    | "It's been 3 months since you connected with [Name]. Want to send a check-in?"           |
| **Event discovery**        | Upcoming industry events, conferences, meetups (user-curated sources)                    |
| **AI boundary**            | Never accesses user's external contacts without explicit import. No automated messaging. |

---

## Mentorship

| Aspect                | Specification                                                                                |
| --------------------- | -------------------------------------------------------------------------------------------- |
| **Purpose**           | Connect users with mentors who can guide their career growth                                 |
| **Mentor matching**   | "Based on your career goals, here are potential mentors in your network or industry"         |
| **Mentor profile**    | Role, experience, expertise areas, availability, mentoring style                             |
| **Mentorship goals**  | Define what the user wants from mentorship (skill guidance, career advice, industry insight) |
| **Session tracking**  | Meeting frequency, topics covered, action items, progress                                    |
| **Becoming a mentor** | Option for senior users to mentor others (gives back to community)                           |
| **AI boundary**       | Never impersonates mentors. Never schedules without user confirmation.                       |

## Weekly Career Review

| Section              | Content                                       | Duration | Layout            |
| -------------------- | --------------------------------------------- | -------- | ----------------- |
| **Progress summary** | Skills developed, apps sent, interviews done  | 15s      | Compact cards     |
| **Key insight**      | AI-generated most important observation       | 10s      | Highlighted quote |
| **Salary check**     | Market update if relevant                     | 10s      | Small card        |
| **Network moment**   | "You haven't connected with [Name] in [time]" | 10s      | Compact reminder  |
| **Next week focus**  | Recommended priority + upcoming deadlines     | 15s      | Action card       |
| **Coach message**    | Personalized message from AI Career Coach     | 20s      | Chat bubble       |

**Timing:** Weekly, Sunday evening. User-configurable.
**Accessibility:** Full keyboard navigation, screen reader support, reduced motion.

## Monthly Career Report

| Section                  | Content                                                   |
| ------------------------ | --------------------------------------------------------- |
| **Overview**             | Career Readiness trend, key changes                       |
| **Skill growth**         | Skills added, proficiency increases, learning consistency |
| **Application pipeline** | Volume, conversion rates, time-to-response                |
| **Network growth**       | New connections, interactions, mentorship progress        |
| **Salary insight**       | Market position change, projected growth                  |
| **Next 30 days**         | Recommended focus areas, upcoming milestones              |
