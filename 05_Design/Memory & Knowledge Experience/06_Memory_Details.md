# Memory Details

**DES-004 — Document 06/16 — Memory & Knowledge Experience**
**Version:** 1.0
**Status:** Final

---

## Purpose

The Memory Detail view shows a **single memory in full** — its content, context, connections, AI summary, and influence on the user's journey. Every detail view answers: Why this exists, How it connects, What it changed, How it influenced later decisions.

## States

| State   | Behavior                                    |
| ------- | ------------------------------------------- |
| Default | Full detail with connections and AI summary |
| Loading | Skeleton matching content layout            |
| Empty   | "This memory doesn't exist" (404)           |
| Offline | Cached version shown                        |
| Editing | Inline edit mode for title, content, tags   |
