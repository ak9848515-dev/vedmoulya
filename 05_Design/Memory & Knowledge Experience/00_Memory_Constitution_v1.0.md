## Preamble

This Constitution establishes the Memory & Knowledge experience for VedMoulya — how users experience their memories, knowledge, learning, growth, and connections. The user should never feel like they are browsing files. Instead, they should feel like they are walking through their own life.

**All specifications follow DES-001 v1.0, DES-002A v1.0, and DES-003A v1.1 exactly.**

## 3. Experience Principles (LOCKED)

1. **Memory must never feel like storage** — it must feel alive, connected, meaningful
2. **Knowledge must never feel like folders** — it must feel organic, discoverable, beautiful
3. **No gamification** — no streaks, badges, levels, XP, leaderboards
4. **Every element explains WHY** — why it exists, how it connects, what it changed
5. **Calm by default** — generous whitespace, progressive disclosure
6. **AI explains, never commands** — the Knowledge Assistant supports discovery
7. **Graph is previewed, never shown in full** — connections are revealed gradually

## 4. Information Hierarchy (LOCKED)

```
P0 — ALWAYS VISIBLE:
  • Navigation (Memory/Knowledge/Reflection tabs)
  • Search bar
  • Current context indicator (which chapter/section)

P1 — SHOWN BY DEFAULT:
  • Memory Timeline (chronological view)
  • Knowledge Garden preview (topic chips, recent connections)
  • Life Chapters navigation (phases of life)
  • Quick Capture button

P2 — CONTEXTUAL:
  • Connections View (when viewing a memory/knowledge item)
  • AI Summary (when viewing an item)
  • Reflection prompts (evening or after meaningful events)
  • Growth visualization (monthly/quarterly)

P3 — ON DEMAND:
  • Full search results
  • Detailed item editing
  • Export/share
```
