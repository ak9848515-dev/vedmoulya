# Learning Settings

> **Document:** DES-007-D13 — Learning Operating System Experience  
> **Status:** 🔒 **LOCKED** — Part of DES-007 Learning Constitution v1.0

---

## Purpose

Learning Settings allows users to control their learning preferences, goals, schedules, and integrations.

---

## Settings Sections

| Section            | Settings                                                 |
| ------------------ | -------------------------------------------------------- |
| **Learning style** | Preferred format (video, reading, hands-on), pace, depth |
| **Schedule**       | Daily learning time, days per week, session duration     |
| **Goals**          | Active learning goals, target areas, certifications      |
| **Notifications**  | Practice reminders, review alerts, weekly review         |
| **Integrations**   | Course import (Coursera, Udemy, edX), bookmarks sync     |
| **Data**           | Export learning history, reset progress                  |
