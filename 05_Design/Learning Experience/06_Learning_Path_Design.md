## Path Types

| Type               | Description                        | AI Role                                  |
| ------------------ | ---------------------------------- | ---------------------------------------- |
| **Skill path**     | Learn a specific skill end-to-end  | Suggests sequence, resources, practice   |
| **Goal path**      | Learn what's needed for a goal     | Maps goal → skills → learning path       |
| **Curiosity path** | Explore a topic without fixed goal | Discovers connections, suggests tangents |
| **Career path**    | Learn for career transition        | Aligns with target role requirements     |
