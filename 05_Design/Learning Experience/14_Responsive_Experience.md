# Responsive Experience

> **Document:** DES-007-D14 — Learning Operating System Experience  
> **Status:** 🔒 **LOCKED** — Part of DES-007 Learning Constitution v1.0

---

## Purpose

The Learning Experience must feel native on every device — from mobile micro-learning on the go to desktop deep learning sessions.

---

## Device Layouts

| Device                | Learning Dashboard                         | Knowledge Map                       | AI Coach           |
| --------------------- | ------------------------------------------ | ----------------------------------- | ------------------ |
| **Mobile (<480px)**   | Single column, today's focus + compact map | Focus on one node cluster at a time | Full-screen chat   |
| **Tablet (768px)**    | 2-column: focus + progress                 | Map with sidebar detail             | Overlay drawer     |
| **Desktop (1280px+)** | Full 4-zone layout                         | Full map with detail + coach        | Side-by-side coach |
