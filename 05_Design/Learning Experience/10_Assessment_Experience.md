---

## Purpose

Assessment measures genuine understanding and capability — not recall. No XP, no points, no gamification. Assessments provide evidence-based mastery indicators.

---

## Assessment Types

| Type                  | Purpose                        | Format                             |
| --------------------- | ------------------------------ | ---------------------------------- |
| **Knowledge check**   | Verify concept understanding   | Open-ended questions, AI evaluates |
| **Application task**  | Apply knowledge to new problem | Scenario-based, project task       |
| **Teaching exercise** | Explain concept to AI          | Feynman technique                  |
| **Project review**    | Evaluate project outcomes      | Rubric-based evaluation            |
| **Confidence check**  | Self-assess certainty          | Confidence scale + knowledge check |

## Mastery Levels

| Level           | Criteria                        | Evidence                     |
| --------------- | ------------------------------- | ---------------------------- |
| **Aware**       | Can recognize concept           | Single knowledge check pass  |
| **Understands** | Can explain concept             | Teaching exercise pass       |
| **Applies**     | Can use in standard scenarios   | Application task pass        |
| **Synthesizes** | Can combine with other concepts | Project review pass          |
| **Masters**     | Can teach others confidently    | All above + confidence check |
