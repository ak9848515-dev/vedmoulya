# Learning Insights

> **Document:** DES-007-D11 — Learning Operating System Experience  
> **Status:** 🔒 **LOCKED** — Part of DES-007 Learning Constitution v1.0

---

## Purpose

Learning Insights provide personalized observations about the user's learning patterns, progress, strengths, gaps, and opportunities — derived from their data, not generic advice.

---

## Insight Types

| Type                   | Example                                                      | Source                  |
| ---------------------- | ------------------------------------------------------------ | ----------------------- |
| **Progress insight**   | "You've completed 60% of your ML path — ahead of schedule."  | Learning progress       |
| **Pattern insight**    | "You learn best through hands-on projects, not reading."     | Learning style analysis |
| **Gap insight**        | "TensorFlow hasn't been practiced in 2 weeks."               | Spaced review schedule  |
| **Connection insight** | "Your Python and Statistics knowledge connects well for ML." | Knowledge Map analysis  |
| **Growth insight**     | "Your knowledge map grew 5 new concepts this month."         | Knowledge Map growth    |
| **Recommendation**     | "Review backpropagation before moving to CNNs."              | AI Learning Coach       |

---

## Weekly Learning Review

| Section              | Content                                              | Duration |
| -------------------- | ---------------------------------------------------- | -------- |
| **Progress**         | Topics covered, skills practiced, assessments passed | 15s      |
| **Knowledge growth** | New connections added, map expansion                 | 15s      |
| **Practice summary** | Reviews completed, confidence changes                | 10s      |
| **Coach insight**    | AI-generated most important observation              | 20s      |
| **Next week**        | Recommended focus areas                              | 15s      |
