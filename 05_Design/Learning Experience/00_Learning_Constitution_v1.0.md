## Preamble

This Constitution establishes the Learning Experience for VedMoulya — a complete Learning Operating System that continuously identifies, prioritizes, delivers, reinforces, applies, measures, and evolves learning based on the user's life. This is NOT an LMS, NOT Coursera, NOT Udemy. Learning is tightly connected to Career, Business, Goals, Execution, Knowledge Graph, Memory, User DNA, Decision Intelligence, and Execution Intelligence.

**All specifications follow DES-001 v1.0 through DES-006 v1.0 exactly.**

## 3. Learning Principles (LOCKED)

1. **Learning is doing** — Every concept must connect to practice, project, or real-world application
2. **Knowledge is connected** — Nothing is learned in isolation. Every concept links to the Knowledge Graph
3. **Mastery over completion** — Progress means understanding, not checking boxes
4. **No gamification** — No XP, no levels, no badges for learning. Progress represents genuine capability
5. **Learning serves goals** — Every learning recommendation ties to a career, business, or life goal
6. **AI teaches, doesn't answer** — The AI Learning Coach explains, questions, challenges, and guides — never simply gives answers
7. **Spaced reinforcement** — Learning is reinforced over time through review, practice, and application

## 5. AI Learning Coach Rules (LOCKED)

| Rule                        | Implementation                                                            |
| --------------------------- | ------------------------------------------------------------------------- |
| **Teaches, doesn't answer** | Explains, questions, challenges, gives hints — never simply gives answers |
| **Source distinction**      | Facts ≠ Examples ≠ Analogies ≠ Hypotheses ≠ Suggestions ≠ Uncertainty     |
| **Socratic method**         | Ask questions before giving explanations                                  |
| **Scaffolding**             | Provide just enough support for the user to reach understanding           |
| **Misconception detection** | Identify and correct incorrect understanding                              |
| **No false confidence**     | "I'm not sure about this. Let's explore it together."                     |
| **Learning over speed**     | Encourage depth over completion                                           |

## 6. Assessment Philosophy (LOCKED)

| Principle              | Implementation                                                          |
| ---------------------- | ----------------------------------------------------------------------- |
| **No XP**              | No points, levels, or badges for learning completion                    |
| **Mastery-based**      | Progress reflects genuine understanding and capability                  |
| **Evidence-based**     | Mastery is demonstrated through application, not multiple choice alone  |
| **Confidence scoring** | "How confident are you in this concept?" alongside objective assessment |
| **Spaced checks**      | Knowledge is re-assessed over time to ensure retention                  |
