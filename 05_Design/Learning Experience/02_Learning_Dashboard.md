# Learning Dashboard

> **Document:** DES-007-D02 — Learning Operating System Experience  
> **Status:** 🔒 **LOCKED** — Part of DES-007 Learning Constitution v1.0

---

## Purpose

The Learning Dashboard is the user's learning home — showing today's learning, current path, progress, and next action. It answers within three seconds: "What should I learn today? Why is it important? What should I do next?"
