## Purpose

Practice Experience provides spaced reinforcement exercises, knowledge checks, and application scenarios that solidify learning over time.

---

## Practice Types

| Type                  | Description                               | Frequency                         |
| --------------------- | ----------------------------------------- | --------------------------------- |
| **Quick check**       | 3-5 question knowledge verification       | After each learning session       |
| **Spaced review**     | Cumulative review at increasing intervals | 1 day → 3 days → 1 week → 1 month |
| **Scenario practice** | Real-world application scenarios          | Weekly                            |
| **Challenge**         | Difficult problems requiring synthesis    | Monthly                           |
| **Teaching exercise** | Explain concept to AI (feynman technique) | User-initiated                    |
