## Purpose

Project-Based Learning connects learning to real-world application. Every project produces evidence, updates the Knowledge Graph, and contributes to career growth.

---

## Project Lifecycle

```
1. DEFINE → What will you build/achieve?
2. PLAN → What skills are needed? What steps?
3. BUILD → Execute the project
4. REFLECT → What did you learn? What would you do differently?
5. EVIDENCE → Capture outcomes, code, designs, feedback
6. UPDATE → Knowledge Graph updated with new skills
```
