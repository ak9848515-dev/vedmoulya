# Learning Journey

> **Document:** DES-007-D03 — Learning Operating System Experience  
> **Status:** 🔒 **LOCKED** — Part of DES-007 Learning Constitution v1.0

---

## Purpose

The Learning Journey shows the user's complete learning path over time — what they've learned, what they're learning, and what they'll learn next. It feels like a progression of understanding, not a list of courses.

---

## Journey View

```
┌────────────────────────────────────────────────────────┐
│  Your Learning Journey                                  │
│                                                         │
│  [Phase: Machine Learning Specialization]               │
│                                                         │
│  Module 1    Module 2    Module 3    Module 4    [Next]│
│  Foundations  Regression  Classification  Neural Nets  │
│  ✓ 95%       ✓ 88%       ✓ 72%          ▶ 40%        │
│                                                         │
│  Connected Knowledge:                                   │
│  Python (Expert) → NumPy (Advanced) → ML (Learning)    │
│                                                         │
│  [Continue Learning]  [Explore Paths]  [Review]        │
└──────────────────────────────────────────────────────────┘
```

---

## Phases

| Phase           | Focus                         | AI Role                                  |
| --------------- | ----------------------------- | ---------------------------------------- |
| **Discovery**   | Exploring what to learn       | Suggests based on goals, gaps, curiosity |
| **Foundation**  | Building core understanding   | Explains concepts, checks comprehension  |
| **Practice**    | Applying knowledge            | Provides exercises, scenarios, projects  |
| **Mastery**     | Deep understanding + teaching | Challenges with complex problems         |
| **Application** | Real-world outcomes           | Connects learning to projects, career    |
