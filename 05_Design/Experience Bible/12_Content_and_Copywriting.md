# Content and Copywriting

> **Document:** DES-010A-D12 — Experience Bible  
> **Status:** 🔒 **LOCKED** — Part of Experience Bible v1.0

---

## Purpose

Content and Copywriting defines the voice and tone of every word in VedMoulya — from button labels and error messages to AI conversations and celebration messages.

---

## Voice Principles

| Principle                     | Rule                                                        |
| ----------------------------- | ----------------------------------------------------------- |
| **Clear over clever**         | Plain language first. Never sacrifice clarity for wordplay. |
| **Warm over corporate**       | Human, not business-like. Write like a thoughtful friend.   |
| **Concise over verbose**      | Say what needs saying, then stop.                           |
| **Honest over hype**          | No exaggeration, no false urgency, no sales language.       |
| **Inclusive over exclusive**  | Everyone should feel addressed. No jargon, no assumptions.  |
| **Empowering over directing** | "You can..." not "Users must..."                            |

## Tone by Context

| Context          | Tone                   | Example                                                 |
| ---------------- | ---------------------- | ------------------------------------------------------- |
| **Onboarding**   | Welcoming, reassuring  | "Welcome. Let's begin your journey."                    |
| **Daily Brief**  | Informative, calm      | "Today, your focus is preparing for the interview."     |
| **AI Coach**     | Supportive, thoughtful | "You've made real progress this week. What's next?"     |
| **Error**        | Apologetic, helpful    | "Something went wrong. Your work was saved. Try again." |
| **Empty state**  | Encouraging, inviting  | "Ready to capture your first memory?"                   |
| **Success**      | Warm, quiet            | "Module complete. Well done."                           |
| **Celebration**  | Meaningful, not hype   | "100 days. That's how expertise is built."              |
| **Reflection**   | Gentle, open-ended     | "What did today teach you?"                             |
| **Confirmation** | Clear, reassuring      | "Your changes have been saved."                         |
| **Notification** | Informative, calm      | "Your mentor has a new availability slot."              |

## Content Rules

| Rule                         | Implementation                                    |
| ---------------------------- | ------------------------------------------------- |
| **No marketing language**    | Never "Amazing!", "Incredible!", "Revolutionary!" |
| **No gamification language** | Never "Level up!", "Achievement unlocked!"        |
| **No urgency**               | Never "Limited time!", "Last chance!"             |
| **No corporate jargon**      | Never "Leverage", "Synergize", "Optimize"         |
| **No technical terms**       | Unless user is in developer context               |
| **Short sentences**          | Aim for 15-20 words average                       |
| **Active voice**             | "You completed" not "was completed by you"        |
| **Positive framing**         | "Save your work" not "Don't forget to save"       |
| **Format for scanning**      | Bullet points, bold key terms, short paragraphs   |
| **One idea per paragraph**   | Helps scanning and comprehension                  |

## Component Copy Standards

| Component          | Copy Standard                        | Example                                              |
| ------------------ | ------------------------------------ | ---------------------------------------------------- |
| **Buttons**        | Verb-first, 1-3 words, sentence case | "Save changes"                                       |
| **Links**          | Descriptive, 2-5 words               | "View your progress"                                 |
| **Empty states**   | Action-oriented, inviting            | "Add your first goal"                                |
| **Error messages** | What happened + what to do           | "Couldn't save. Your internet connection was lost."  |
| **Labels**         | Clear, 1-2 words                     | "Email address"                                      |
| **Placeholders**   | Example or hint                      | "e.g. you@example.com"                               |
| **Tooltips**       | Brief explanation                    | "Your trust score increases when projects complete." |
| **Notifications**  | What happened + optional action      | "Your proposal was viewed. [View response]"          |
| **AI messages**    | Natural, first-person                | "I noticed you've been exploring ML roles."          |

## Celebration Copy Rules

| Rule                     | Implementation                                               |
| ------------------------ | ------------------------------------------------------------ |
| **Growth framed**        | "You've been consistent for 30 days. That builds expertise." |
| **Never hype**           | No "AMAZING!", no "INCREDIBLE!", no all-caps                 |
| **Never gamification**   | No "Level 3!", no "Achievement unlocked!"                    |
| **Quiet acknowledgment** | Simple, sincere recognition of effort                        |
| **Context-specific**     | "30 days of learning. Your knowledge graph is growing."      |
| **Once per week max**    | Celebrations are rare to maintain meaning                    |

---

## AI Copy Rules

| Rule             | Implementation                                       |
| ---------------- | ---------------------------------------------------- |
| **First person** | "I think..." not "The system thinks..."              |
| **Humble**       | "I'm not certain, but..." over confident speculation |
| **Transparent**  | "I'm suggesting this because..."                     |
| **Concise**      | Short paragraphs, one idea at a time                 |
| **Natural**      | Conversational, not robotic                          |
| **Labeled**      | Always clear that user is talking to AI              |

## Quality Review

| Dimension           | Assessment                                                                                               |
| ------------------- | -------------------------------------------------------------------------------------------------------- |
| **Why**             | Every word in the product shapes user perception — wrong words destroy trust                             |
| **Psychology**      | Framing effect — how something is said changes how it's received; loss aversion — avoid negative framing |
| **Accessibility**   | Clear language benefits everyone, especially non-native speakers and cognitive disabilities              |
| **Engineering**     | Copy is centralized in i18n files for consistency and translation readiness                              |
| **Performance**     | Copy has no performance impact                                                                           |
| **Scalability**     | Voice and tone guidelines scale to any new feature                                                       |
| **DES Consistency** | New — elevates scattered copy guidelines into unified standard                                           |
