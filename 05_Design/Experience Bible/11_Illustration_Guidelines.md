# Illustration Guidelines

> **Document:** DES-010A-D11 — Experience Bible  
> **Status:** 🔒 **LOCKED** — Part of Experience Bible v1.0

---

## Purpose

Illustration Guidelines define the illustration style for VedMoulya — when to use illustrations, what they should look like, and how they should behave.

---

## Illustration Philosophy

| Principle      | Rule                                                              |
| -------------- | ----------------------------------------------------------------- |
| **Purposeful** | Every illustration serves a functional purpose — never decorative |
| **Simple**     | Minimal detail, clean lines, generous negative space              |
| **Warm**       | Human, approachable, never corporate                              |
| **Consistent** | Same style across all illustrations                               |
| **Calm**       | Soft colors, gentle shapes, no aggressive visuals                 |

---

## When to Use Illustrations

| Context        | Illustration                              | Avoid                         |
| -------------- | ----------------------------------------- | ----------------------------- |
| Empty states   | Friendly scene related to missing content | Generic "no data" icons       |
| Success states | Celebration scene                         | Confetti, fireworks           |
| Onboarding     | Life journey scenes                       | Product feature illustrations |
| Error states   | Gentle, reassuring scene                  | Alarming visuals              |
| AI presence    | Subtle, intelligent motif                 | Robotics, sci-fi themes       |

---

## Illustration Style

| Property           | Standard                                     |
| ------------------ | -------------------------------------------- |
| **Style**          | Flat vector with subtle gradients            |
| **Colors**         | Brand palette only                           |
| **Characters**     | Diverse, inclusive, stylized (not realistic) |
| **Faces**          | Simple features, warm expressions            |
| **Backgrounds**    | Soft, minimal, brand colors                  |
| **Animation**      | Subtle motion only — gentle parallax or fade |
| **Reduced motion** | Static fallback for all illustrations        |

---

## Quality Review

| Dimension           | Assessment                                                                                 |
| ------------------- | ------------------------------------------------------------------------------------------ |
| **Why**             | Illustrations add personality and warmth — but wrong illustrations damage brand perception |
| **Psychology**      | Emotional design — appropriate illustrations create positive emotional associations        |
| **Accessibility**   | All illustrations require alt text; animations respect reduced motion                      |
| **Engineering**     | SVG format for resolution independence                                                     |
| **Performance**     | Optimized SVGs, lazy-loaded, animated only when visible                                    |
| **Scalability**     | Consistent style guide ensures new illustrations match existing ones                       |
| **DES Consistency** | New — no prior illustration guidelines existed                                             |
