## Purpose

The Idea Studio is a premium experience where users transform observations, problems, and ideas into validated business opportunities. It is the heart of the Business Experience.

## Idea Lifecycle

```
1. CAPTURE → Quick idea entry (title + problem + observation source)
2. MAP → Problem mapping + customer persona + value hypothesis
3. VALIDATE → Customer conversations + experiments + evidence
4. DECIDE → Go / Pivot / Park (based on evidence, not gut)
5. CONNECT → Link to Knowledge Graph + Learning + Career
6. BUILD → MVP planning (when validated)
```

## Idea Elements

| Element                   | Description                                       | Display          |
| ------------------------- | ------------------------------------------------- | ---------------- |
| **Idea Capture**          | Title, problem statement, source of observation   | Top of card      |
| **Problem Mapping**       | Who has this problem? Why now?                    | Card section     |
| **Validation Status**     | % validated, assumptions tested vs untested       | Progress bar     |
| **Customer Value**        | What value does the solution deliver? Quantified. | Card section     |
| **Competitive Landscape** | Competitors, gaps, differentiation                | Card section     |
| **Evidence**              | Interviews, experiments, data collected           | Log entries      |
| **Decision History**      | Key decisions made + rationale                    | Timeline         |
| **Knowledge Graph links** | Related concepts, technologies, domains           | Connection chips |
| **Learning links**        | Related courses, skills being developed           | Learning chips   |
| **Career links**          | How this builds career direction                  | Career chip      |
