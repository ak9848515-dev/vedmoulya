## Description

User stories for the Core module of the VedMoulya platform.

---

## Epic: User Onboarding

- As a new user, I want to create my profile so that the platform can personalize my experience.
- As a new user, I want to define my goals so that the platform can guide my journey.
- As a new user, I want to complete an initial skills assessment so that my starting point is known.

## Epic: Journey Tracking

- As a user, I want to see my current journey stage so that I know where I am.
- As a user, I want to understand what actions advance me to the next stage.
- As a user, I want to track my progress over time so that I can see my growth.

## Epic: HPI Dashboard

- As a user, I want to view my Human Progress Index score.
- As a user, I want to see how my HPI changes over time.
- As a user, I want to understand which actions improve my HPI.
