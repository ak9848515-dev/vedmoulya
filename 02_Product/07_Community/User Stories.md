## Description

User stories for the Community module.

## Epic: Community Participation

- As a user, I want to join groups based on my interests.
- As a user, I want to participate in discussions and ask questions.
- As a user, I want to connect with peers on similar journeys.

## Epic: Recognition

- As a user, I want to celebrate my achievements with the community.
- As a user, I want to see and celebrate others' achievements.
- As a user, I want to receive recognition from the community.
