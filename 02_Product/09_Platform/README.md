The Platform module defines the core platform infrastructure — settings, security, administration, and cross-cutting concerns that support all other modules.

## Purpose

Provide the foundational platform services, administrative tools, and system-wide settings that ensure the VedMoulya platform operates securely, reliably, and efficiently.

- Support platform analytics and reporting
- Enable system integration and extensibility
- Manage platform-wide notifications and communication
