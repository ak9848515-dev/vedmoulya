## Description

User stories for the Discover module.

## Epic: Opportunity Discovery

- As a user, I want to discover career paths matching my skills and interests.
- As a user, I want to see opportunities I hadn't considered before.
- As a user, I want to understand the requirements and timeline for each opportunity.

## Epic: Skill Exploration

- As a user, I want to browse skills related to my interests.
- As a user, I want to see how different skills connect and build on each other.
- As a user, I want to find learning resources for any skill I discover.

## Epic: Social Discovery

- As a user, I want to find mentors in my areas of interest.
- As a user, I want to discover peers with similar goals.
- As a user, I want to explore communities relevant to my journey.
