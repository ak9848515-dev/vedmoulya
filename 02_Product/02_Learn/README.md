## Description

The Learning module delivers personalized learning experiences, skill development paths, assessments, and knowledge verification.

---

## Purpose

Empower users to acquire knowledge and skills through structured learning paths, interactive content, and verified assessments.

## Responsibilities

- Deliver personalized learning paths aligned with user goals
- Manage learning content (courses, lessons, quizzes)
- Track learning progress and mastery
- Assess and verify knowledge acquisition
- Recommend next steps based on learning gaps
