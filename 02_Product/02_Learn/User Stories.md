## Description

User stories for the Learn module.

## Epic: Learning Paths

- As a user, I want an AI-generated learning path tailored to my goals.
- As a user, I want to see the estimated time for each learning path.
- As a user, I want to track my progress through each course or path.

## Epic: Assessments

- As a user, I want to test my knowledge after completing a course.
- As a user, I want to receive feedback on my assessment results.
- As a user, I want to earn certificates for completed learning.

## Epic: Progress

- As a user, I want to see my overall learning progress dashboard.
- As a user, I want reminders for spaced repetition reviews.
- As a user, I want to see how my learning impacts my HPI.
