## Description

Defines the systematic methodology used to discover, validate, and document human problems for the VedMoulya Human Problems Repository.

---

## Research Philosophy

VedMoulya follows a **mixed-methods research approach** combining qualitative depth with quantitative validation:

- **Qualitative first** — Understand the problem deeply through interviews, observations, and open-ended exploration.
- **Quantitative second** — Validate prevalence, severity, and frequency through surveys, market data, and analytics.
- **Continuous iteration** — Problems are living artifacts that evolve as new evidence emerges.

## Research Methods

| Method             | Type         | When Used                        | Output                           |
| ------------------ | ------------ | -------------------------------- | -------------------------------- |
| User Interviews    | Qualitative  | Problem discovery & exploration  | Rich narratives, quotes, context |
| Surveys            | Quantitative | Problem validation at scale      | Statistical prevalence data      |
| Community Research | Qualitative  | Understanding shared experiences | Pattern identification           |
| Industry Reports   | Quantitative | Market validation                | Market size, trends              |
| Market Data        | Quantitative | Opportunity sizing               | Revenue potential, TAM           |
| Founder Experience | Qualitative  | Internal pattern recognition     | First-principles insights        |
| Expert Interviews  | Qualitative  | Domain validation                | Subject matter expertise         |

## Research Workflow

### Phase 1: Discovery

1. Identify a potential problem domain through:
   - Interview signals
   - Community observations
   - Market trend analysis
   - Founder experience
   - Industry report findings
2. Document initial hypothesis using the Problem Template
3. Set research status to **Hypothesis**

### Phase 2: Exploration

1. Conduct 3-5 exploratory interviews with people experiencing the problem
2. Document patterns, quotes, and observations
3. Update problem description based on findings
4. Set research status to **Exploring**

### Phase 3: Validation

1. Select validation method(s) from the Problem Validation Framework
2. Execute validation research
3. Update problem with evidence and scores
4. Set research status to **Validated** or **Invalidated**

### Phase 4: Prioritization

1. Score the problem using the Problem Prioritization Framework
2. Compare against existing problems
3. Decide on product response
4. Set research status to **Prioritized** or **On Hold**

### Phase 5: Monitoring

1. Track if the problem evolves over time
2. Update evidence as new data emerges
3. Re-validate if significant changes occur
4. Set research status to **Active** or **Archived**

## Ethical Guidelines

- Always obtain informed consent from research participants
- Anonymize all personal data in research artifacts
- Never manipulate or lead participants during interviews
- Acknowledge biases and limitations in research findings
- Share research insights transparently across the organization
