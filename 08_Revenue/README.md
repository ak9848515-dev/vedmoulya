## The Verified-Payment Philosophy

VedMoulya strictly differentiates between wishful thinking and true commercial proof:

```
[ HYPOTHESIS ] ──► [ DISCOVERY ] ──► [ WILLINGNESS-TO-PAY ] ──► [ REVENUE_VERIFIED ]
   (Idea)            (Interview)          (Verbal Interest)        (Bank Settled Payment)
```

- **Interest ≠ Revenue:** A prospect saying "I love this idea" is categorized under `HYPOTHESIS`.
- **Willingness-to-Pay ≠ Payment:** A verbal agreement or unsigned quote remains `OPPORTUNITY`.
- **Verified Payment:** Only an actual, bank-settled or gateway-reconciled transaction unlocks the `REVENUE_VERIFIED` milestone in the user's Human Progress Index.
