# @vedmoulya/ui

**Purpose:** Design system components — reusable UI components, design tokens, and icon library shared across all frontend applications.

**Owner:** Engineering Team — Frontend

## Contents

- `src/components/` — Reusable UI components
- `src/tokens/` — Design tokens (colors, spacing, typography)
- `src/icons/` — SVG icon library

## Dependencies

- `@vedmoulya/core` — Base types and utilities

## Usage

```typescript
import { Button, Card, Input } from '@vedmoulya/ui';
```

## Future Expansion

- Component library with Storybook documentation
- Accessibility-compliant components (WCAG 2.1 AA)
- Theme system with light/dark mode
- Animation and transition primitives
