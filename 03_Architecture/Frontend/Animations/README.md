## Purpose

Define animation principles, patterns, and implementations that enhance user experience through purposeful, performant motion design.

## Scope

- Animation principles and design guidelines
- Micro-interactions (button states, hover effects, feedback)
- Page transitions and view navigations
- Loading and skeleton animations
- Data visualization animations
- Gesture-driven animations (swipe, pinch, drag)
- Accessibility preferences (reduced motion support)

## Responsibilities

- Implement animations that serve functional purposes
- Maintain animation performance at 60fps
- Respect reduced motion accessibility settings
- Provide reusable animation primitives and hooks
- Document animation patterns with usage guidance
- Ensure animations are culturally appropriate and inclusive
