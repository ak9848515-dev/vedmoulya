# @vedmoulya/knowledge — Knowledge Service

**Purpose:** Knowledge backend service. Provides domain logic and API endpoints for the knowledge bounded context.

**Owner:** Engineering Team — Backend

## Dependencies

- `@vedmoulya/core` — Base types, errors, configuration
- `@vedmoulya/domain` — Domain entity types

## Structure

- `src/domain/` — Business entities and domain rules
- `src/application/` — Use cases and application logic
- `src/infrastructure/` — Data access and external adapters
- `src/presentation/` — API controllers and routes
